## Target rules

A request URL must be:

- an absolute `http` or `https` URL, at most 2048 bytes;
- credential-free (no userinfo);
- port-free (no explicit `:port`);
- a multi-label domain — single labels, IP literals and private/reserved
  suffixes such as `localhost`, `.local`, `.internal`, `.arpa`, `.onion`
  are refused with `blocked_target`.

Every redirect hop is re-validated with the same rules, and `https → http`
downgrades are refused. At most five redirects are followed.

## Public-address enforcement

Both adapters verify that targets resolve only to public addresses.

- IPv4 denies: `0/8`, `10/8`, `100.64/10`, `127/8`, `169.254/16`,
  `172.16/12`, `192.0.0/24`, `192.0.2/24`, `192.88.99/24`, `192.168/16`,
  `198.18/15`, `198.51.100/24`, `203.0.113/24`, `224/4`, `240/4`.
- IPv6: only `2000::/3` minus `2001::/23`, `2001:db8::/32`, `2002::/16`,
  `3fff::/20`; IPv4-mapped addresses use the IPv4 rules.

**Native:** reqwest resolves through a custom resolver that drops all
non-public answers before connecting — the client never opens a socket to a
private address, so DNS rebinding does not help an attacker.

**Worker:** `global_fetch_strictly_public` forces upstream fetches to route
as public internet traffic and blocks same-zone origin bypass.

## Limits

- 1 MiB response cap, 4 s total budget (all hops), 3 s connect timeout.
- Per-client-IP: 60 requests/minute sustained, 120 burst (429 +
  `Retry-After`; the Worker binding reports a fixed 60 s). Clients whose
  IP cannot be extracted share one bucket — they are limited together,
  never exempted.
- Per-target-host: 120 requests/minute (429 + `Retry-After`).
- Upstream pages larger than 1 MiB are rejected with 413.
- Concurrency is capped (default 512); excess load is shed with 503.

## Privacy

Each request produces one structured JSON log line with method, route,
status, latency, cache result, target host and a 12-hex-char SHA-256
fingerprint of the normalized URL. The full URL, query strings, page
content, metadata content and the client IP are never logged.
