title: corx

---

corx turns a URL into the metadata needed to render a link card: title,
description, site name, image, favicon, theme color and more.

The workspace has three crates:

- `corx` — pure core: URL validation, SSRF rules, redirect policy, streaming
  HTML metadata extraction, response shaping and CORS. No I/O; compiles for
  native and `wasm32-unknown-unknown`.
- `corx-server` — native binary on Axum + reqwest.
- `corx-worker` — Cloudflare Worker built with workers-rs.

## Quick start

```bash
cargo run -p corx-server -- --allowed-origins https://app.example.com
curl "http://localhost:8080/v1/preview?url=https%3A%2F%2Fexample.com"
```
