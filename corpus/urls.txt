# corx corpus: one URL per line, then a minimum expectation.
#
#   any                    informational, no expectation (bot walls, volatile pages)
#   page                   any page result
#   page:T+I               a page with the listed fields (T title, D description,
#                          S siteName, I image, F favicon)
#   page/oembed:T          a page produced by the oEmbed fallback
#   media                  any media result
#   media:image/*          a media result whose mediaType matches (exact or type/*)
#   error:<slug>           exactly this error slug
#
# The web changes: expectations are minimums observed to hold, not promises.
